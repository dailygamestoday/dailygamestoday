# Daily Games Today

[Daily Games Today](https://dailygames.today/) is a collection of short browser games. Try today’s pick, browse for a different kind of challenge, or keep your favorites in your browser. The directory and guides are maintained here by the site’s team. Each game is credited to its creator.

## Four games to try

| Game | What you do |
| --- | --- |
| [Daily Orbs](https://dailygames.today/games/daily-orbs/) | Choose which challenges to tackle on a shared board and try to collect six orbs. |
| [Magnitudle](https://dailygames.today/games/magnitudle/) | Estimate a real-world quantity and see how close your number was. |
| [Medical Krillion](https://dailygames.today/games/medical-krillion/) | Work through seven fictional cases and see how the game scores your guesses. |
| [Wonderhop](https://dailygames.today/games/wonderhop/) | Choose a direction and look for a common, rare, older, or newer answer. |

## Suggest a game or report a correction

Open an issue with the game’s official URL and one sentence about how it plays. For a correction, include the affected page, the detail to fix, and any steps or source that can help the editors reproduce it. Keep puzzle answers and private player information out of issue titles.

The repository holds public documentation and feedback for the directory. Game software, artwork and trademarks belong to their respective owners. For issues that need a private reply, write to [support@dailygames.today](mailto:support@dailygames.today).
